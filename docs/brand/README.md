# Brand

<img src="icon.svg" width="160" alt="Rounds app icon" />

The mark is a progress ring three quarters complete, filling clockwise from the top like the rings on the workout screen, around an **R** set in Big Shoulders Display ExtraBold.

| File                     | Use                                                                                  |
| ------------------------ | ------------------------------------------------------------------------------------ |
| `icon.svg`               | iOS / App Store icon: white mark on vermilion `#CC4118`, full bleed                  |
| `android-foreground.svg` | Android adaptive icon foreground, inside the 66% safe zone (background is `#CC4118`) |
| `android-monochrome.svg` | Android themed (monochrome) icon                                                     |
| `splash.svg`             | Splash screen mark: vermilion on white                                               |

The PNGs in `apps/mobile/assets/images` are rendered from these files at 1024 × 1024.
